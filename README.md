## 🛠️ เครื่องมือที่ใช้ในหลักสูตร

### Languages & Frameworks
- **Node.js** (Express, Fastify, NestJS)
- **Python** (FastAPI, Flask)
- **Go** (Gin, Echo)
- **Java** (Spring Boot, Quarkus)

### Infrastructure & Container
- **Docker** & **Docker Compose**
- **Kubernetes** (K8s)
- **Helm**
- **Istio** (Service Mesh)

### Databases
- **PostgreSQL** - Relational
- **MongoDB** - Document
- **Redis** - Cache/Session
- **Elasticsearch** - Search
- **Cassandra** - Wide Column

### Messaging & Streaming
- **RabbitMQ**
- **Apache Kafka**
- **NATS**

### Observability
- **Prometheus** + **Grafana**
- **Jaeger** (Distributed Tracing)
- **ELK Stack** (Elasticsearch, Logstash, Kibana)

### Cloud Platforms
- **AWS** (EKS, ECR, RDS, SQS, SNS)
- **GCP** (GKE, Cloud Run, Pub/Sub)
- **Azure** (AKS, Azure Service Bus)

## 📋 ข้อกำหนดเบื้องต้น

- ความรู้พื้นฐาน Programming (ภาษาใดก็ได้)
- เข้าใจ HTTP/REST API เบื้องต้น
- ใช้ Terminal/Command Line ได้
- มี Docker Desktop ติดตั้งแล้ว (แนะนำ)

## 🎯 เป้าหมายของหลักสูตร

เมื่อจบหลักสูตร คุณจะสามารถ:
1. **ออกแบบ** ระบบ Microservices ตั้งแต่ศูนย์
2. **พัฒนา** Services ด้วยหลายภาษา
3. **Deploy** ระบบบน Cloud และ Kubernetes
4. **Monitor** และ **Debug** ระบบ Production
5. **Scale** ระบบรองรับผู้ใช้หลักล้านคน
6. **นำทีม** พัฒนา Microservices ได้อย่างมืออาชีพ
